# Правила проекта 1С

- Перед изменением кода прочитать локальные инструкции проекта и `.pipeline/pipeline.json`.
- Код BSL, комментарии и сообщения времени выполнения писать на русском языке.
- Перед реализацией проверять метаданные и существующие решения проекта; не выдумывать объекты платформы и функции БСП.
- Каждое изменение должно пройти обязательный VERIFY из установленного pipeline.
