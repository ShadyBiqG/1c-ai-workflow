# Задача разработки

Использовать persisted workflow из `.codex/skills/onec-pipeline`:

1. Создать или возобновить задачу.
2. Завершить PLAN и сохранить `plan.md`.
3. Выполнить WORK.
4. Обязательно запустить VERIFY.
5. Следовать маршруту READY/REVIEW из `.pipeline/pipeline.yaml`.

Commit выполнять только по явному запросу пользователя.
