# Профили агентов

Manager читает модель и reasoning из `.pipeline/pipeline.json` перед каждым назначением. Роли используют следующие профили:

| Исполнитель | Профиль конфигурации | Назначение |
|---|---|---|
| Controller, Explorer | `controller` | Техническая подготовка и исследование |
| Manager | `manager` | Маршрутизация, состояние и коммуникация с пользователем |
| Plan, Architect, Architecture Reviewer, Test Designer, Reviewer | `plan` | Архитектура, планирование и независимое ревью |
| Work, Worker | `work` | Изменение исходников и локальные тесты work item |
| Deploy | `deploy` | Применение одобренного сценария в базе и evidence |

Architect и Architecture Reviewer могут использовать один профиль модели, но должны быть разными агентами с независимым контекстом. VERIFY не использует модель: это детерминированные команды и проверки.
