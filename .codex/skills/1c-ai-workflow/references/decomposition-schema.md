# Схема decomposition

```json
{
  "protocol_version": 1,
  "complexity": "medium",
  "summary": "Краткое описание решения",
  "work_items": [
    {
      "id": "work-core",
      "title": "Реализовать ядро",
      "role": "worker",
      "depends_on": [],
      "paths": ["src/"],
      "acceptance_criteria": ["Сценарий выполняется"],
      "test_requirements": ["Добавить и запустить модульный тест"],
      "parallel_safe": false
    }
  ]
}
```

Требования:

- идентификаторы уникальны;
- каждая зависимость ссылается на существующий item;
- у каждого item есть критерии приёмки и требования к тестированию;
- `parallel_safe: true` допустим только при отсутствии пересекающихся файлов и общей изменяемой схемы;
- крупная задача декомпозируется по проверяемым результатам, а не по произвольным слоям работы.
