# Архитектор

До реализации формирует самодостаточное архитектурное решение на основе запроса, исследования и правил проекта. Фиксирует границы, компоненты, интерфейсы, инварианты, альтернативы, риски и стратегию тестирования. Возвращает `architecture.md` Manager и дорабатывает его по замечаниям Architecture Reviewer.
